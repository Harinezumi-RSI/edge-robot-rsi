# 動画の台本(第 4 版の下書き、10/25。実際のナレーションと秒数は `kitchen/make_video.py` の plan() が正)

題: **エッジで動く AI ロボットを、家庭用パソコンで RSI**(人の案、10/23)
副題: Wi-Fi なしで動き、Mac mini 1 台で自分を鍛える家事ロボット

テーマ: 動くとき(耳・頭・目・手・口)はすべて Mac mini の中でネットにつながらない(エッジ)。鍛えるとき(練習 → 自分で採点 → 学び直し)も
Mac mini の中で回る(RSI)。仮説を立てて採否を決めるコーチだけがパソコンの Claude(鍛えるときだけネットを使う)。
デモ映像の中の声は公開モデルで Wi-Fi なしで動く(コーチとロボットの声 = Irodori-TTS、ロボットの耳 = Qwen3-ASR)。ナレーションだけは GCP の Text-to-Speech(Chirp3-HD の落ち着いた男性の声 Charon)で、ロボットとコーチの声と聞き分けやすくする(10/24 人の案)。macOS の say は使わない。
長さ 2 分 30 秒〜2 分 55 秒(上限 3 分)。個人の情報(名前・アカウント・パスの入った画面)は映さない。Claude の画面は作った板で見せる。
【】は最終テスト(初期状態 40〜49、1 回だけ)の数字で差し替える。判断用の数字は「判断用」と書いて出す。

撮り直しの注意:
- 2 の発話は、頭が読み違えないものを選ぶ(1 本目は「寒くなってきたね…」で頭が「チーズを器 + 火」と読み違えて聞き返した)。
  一度で決まる場面と、聞き返して言い直しで直る場面は分けて撮る。どちらも 1 回撮りで、選んだことは概要欄と報告書に書く。

- 手は最終の対応表(通しで決めたもの)で撮る。デモ用に別の手を選ばない。
