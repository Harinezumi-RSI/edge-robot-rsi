# 研究のループの記録(Claude が回す外側のループ)

設計方針(10/22、人): 外側の研究ループの実行は Claude に任せ、各周の所要時間と結果を記録する。
外側のループ = Claude が結果を見て仮説を立て、コード・設定・データの選び方を変えて次を回し、採否を決める。人は介入しない。
内側のループ = ロボットの練習 → 改造 Jev で自分で採点 → 追加学習 → 評価(ミニ RSI)。
時間と本数の機械向けの記録は `docs/rsi_runs.jsonl`(`python kitchen/runlog.py table` で表)。

## 決まり(ループの前に固定)
- 初期状態: 練習・学習 = 10〜39、Claude の判断用(検証)= 0〜9、**最終テスト = 40〜49(ループ中は一度も使わない。最後に 1 回だけ)**。
  何度も測って選ぶことによる水増しを最終の数字から外すため。発話 30 本も最後まで手本・調整に使わない。
- 触る範囲: `~/dev/pai-final` の中だけ。同じ Mac のほかの重い処理とは、Mac の鍵を 1 回分ずつ取り合うだけ。外部への投稿・提出はしない。
- ディスク: 空きが 10GB を切ったら止めて人に知らせる(同じ Mac のほかの作業に 15GB 要るため、増やすのは数 GB まで)。
- 判断は対応比較(同じ初期状態・同じ波の種)で読み、差が偶然で出る見込み(符号検定)を書く。
